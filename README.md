## 🌟 About the Project

This is a modern, responsive, and kid-friendly web application for **VETRI VIVEKANANDA Nursery and Primary School**, located in T.Mariyur, Ramanathapuram District, Tamil Nadu.

Built with **React (JSX)**, **Vite**, and styled with custom kid-appealing CSS, playful Google Fonts, and interactive Web Audio sound effects.

---

## 🎨 Key Features

- **🌈 Cheerful & Kid-Attractive Design**: Playful colors, bouncy animations, rounded cards, and custom mascot **"Vetri"** (the 3D elephant).
- **🔊 Interactive Web Audio FX**: Built-in sound effects (pops, chimes, victory fanfare) with an easy audio toggle.
- **📚 Dynamic Academics Timetable**: Interactive tabbed curriculum and daily schedule for **Nursery & KG (Ages 2.5–5)** and **Primary School (Std 1–5)**.
- **📸 47+ Photo Gallery & Full-Screen Lightbox**: Filterable albums for Campus & Classrooms, Van Transport Fleet, Annual Day, Educational Tours, and Silambam & Sports.
- **🎬 Integrated Video Showcase**: HTML5 player for the **Sports Day Parade (`paraid1.mp4`)** and modal players for school YouTube performances.
- **🚌 5-Van Transportation Fleet**: Route coverage guide with safety highlights and door-to-door village pick-up details.
- **🎮 Kids' Wonder & Phonics Zone**: Interactive alphabet cards (A–H) with phonetic hints and live star counter with confetti celebrations.
- **📝 Online Admission Inquiry**: Step-by-step admission roadmap, required documents checklist, expandable FAQ accordion, and an interactive pop-up form.
- **📱 Fully Responsive**: Optimized for smartphones, tablets, laptops, and desktops.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ritiz10/VVN-School.git
   cd VVN-School
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
